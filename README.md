# raw-claude

A super-animated deep-dive into the Claude Code agent — built with Next.js 15, Framer Motion, and Tailwind CSS.

## Package Manager: bun

This project uses [bun](https://bun.sh) — the Rust-based all-in-one JS runtime & package manager.

```bash
# Install dependencies
bun install

# Start dev server
bun dev

# Production build
bun run build

# Start production server
bun start

# Type-check
bun run type-check

# Lint
bun run lint
```

> Vercel automatically detects the `bun.lockb` file and uses bun for all install, build, and lint steps during deployment.
